U04 LOG

03What this is

A self-contained proof that a box can go from "doesn't exist" to "serving traffic" without a human touching a console. Terraform declares the infrastructure — the EC2 instance, its security group, its networking — as code that can be reviewed, versioned, and destroyed as cleanly as it was created. Ansible then reaches over SSH and brings that blank box to a known, repeatable state: installs Docker, pulls the image, gets it running. Docker keeps the app itself portable — the same container that runs here would run identically on a laptop, a Raspberry Pi, or a fleet of production servers.

The point isn't the app on screen — it's everything behind it. This page exists to make that invisible work visible: every section above and below is a real piece of the pipeline that shipped it.

05What actually went wrong

Nothing here shipped on the first try, and that's the more honest part of the story.

VM networking
Adapter left on host-only — no DHCP lease, no route out. Fixed at the hypervisor, not inside the guest OS.
Local browser
curl worked, Chrome didn't — a system proxy setting Chrome honored and curl ignored.
Git auth
Password auth over HTTPS was rejected — GitHub requires a scoped personal access token instead.
